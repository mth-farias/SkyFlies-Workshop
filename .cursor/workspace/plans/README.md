# plans

Active implementation plans from `fly-plan`, one file per plan. Critique
with `fly-plan-improve` before executing. After execute, `fly-review-plan`.
Plan only after the user asks (`fly-confirm-align` is chat-only). When a
plan is complete or superseded, `fly-handoff` moves it to
`workspace/archive/` (ask if unsure). Student plan bodies are gitignored;
this README stays.
